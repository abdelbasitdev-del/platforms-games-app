# 🎮 Platforms Games App

A beautiful cross-platform games collection built with Flutter. Includes multiple mini-games and a clean About page.

## ✨ Features
- 🎯 Multiple platform games in one app
- 🎨 Clean and modern UI
- 📱 Works on Android, iOS, Web, Windows
- ℹ️ About page

## 🛠️ Built With
- Flutter & Dart

## 🚀 How to Run
flutter pub get
flutter run
